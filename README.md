# Mochi Press

A free archive utility for macOS. Open, extract and create ZIP, 7z, RAR, TAR and more, right from Finder.

**[Download the latest version](https://github.com/halebop17/mochi-releases/releases/latest)**. Open the DMG and drag Mochi Press to Applications.

Requires macOS 14 Sonoma or later.

## Features

- Browse archives before extracting, and extract only what you need
- Compress files and folders to ZIP, 7z and other formats, with reusable presets
- Finder Quick Actions and Services: right-click → Compress or Extract with Mochi Press
- Password-protected archives
- Automatic updates

## About this repository

This repository hosts Mochi Press releases and its update feed (`appcast.xml`). The app's source code is not public.
